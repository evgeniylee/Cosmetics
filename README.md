# NABI — интернет-магазин корейской косметики

Next.js 15 (App Router) + Tailwind CSS 4 + TypeScript + PostgreSQL. Языки RU/UZ, mobile-first.
Полное ТЗ: `docs/prompt.md`. Промты для изображений: `docs/image-prompts.md`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000 → /ru
```

Устанавливать PostgreSQL локально не нужно: без `DATABASE_URL` используется встроенная база PGlite,
данные лежат в `./.data/pglite` (в git не попадают). Чтобы начать с чистой базы, удалите папку `.data`.

В `npm run dev` вход работает в демо-режиме: код подтверждения `111111`.

Админка: создайте `.env.local` со строкой `ADMIN_PHONES=+998901234567` (ваш номер), перезапустите
сервер и откройте http://localhost:3000/admin.

Продакшен-сборка: `npm run build && npm start`. Настройки — в `.env.local` по образцу `.env.example`.

## Что готово

**Этап 1 — витрина.** Дизайн-система, поиск с транслитом, главная с каруселью, каталог с фильтрами,
страница товара, корзина с промокодами креаторов, анимации, меню каталога, аналитика `track()`.

**Этап 2 — бэкенд.**
- База данных: клиенты, адреса, анкета (вопросы хранятся в таблице `profile_questions`), сессии,
  коды подтверждения, заказы, события. Миграции в `src/server/migrations.ts` применяются автоматически.
- Вход по телефону через Telegram Gateway: `checkSendAbility` → `sendVerificationMessage` →
  `checkVerificationStatus`. Лимиты: 3 кода на номер за 15 минут, 5 номеров с одного IP в час,
  5 попыток ввода на код. Сессия в httpOnly-куке на 90 дней.
- Анкета нового клиента: имя, фамилия, дата рождения (14+), согласие, подписка на акции. Привязка
  к UTM и коду креатора из первого визита.
- Нет Telegram у номера — заказ принимается без кода со статусом «Требует звонка».
- Заказы: цены, скидки и доставка считаются только на сервере. Уведомление о каждом заказе
  приходит в Telegram-чат менеджера.
- Профиль: заказы со статусами, «Купить снова», заполненность профиля, выход.

**Этап 3 — админка** (`/admin`, вход тем же кодом из Telegram, доступ по списку `ADMIN_PHONES`).
- Сводка: заказы и выручка за сегодня, 7 и 30 дней, прибыль и маржа по себестоимости, доля
  повторных покупателей, топ товаров, креаторы и комиссия к выплате.
- Заказы: фильтры по статусам, поиск по номеру, имени, телефону и адресу, карточка заказа с кнопкой
  следующего шага, отметкой оплаты, заметкой менеджера и историей статусов. Выгрузка в Excel.
- Товары: каталог теперь в базе. Список с маржой и продажами за 30 дней, быстрые переключатели
  «на сайте» и наличия, форма с текстами RU/UZ, загрузкой фото (сжимаются в браузере) и живым
  расчётом маржи. Выгрузка и загрузка Excel: сначала показываем, что изменится, при любой ошибке
  в файле ничего не применяется.
- Клиенты: сегменты (новые, повторные, VIP от 2 млн, спящие 60+ дней, именинники месяца, согласные
  на рассылку), карточка с заказами, анкетой, событиями и заметкой. Выгрузка в Excel.
- Промокоды: скидка, комиссия, подборка креатора на главной, статистика, ссылка для креатора
  (`/ru?promo=CODE` — промокод применяется сам).

**Варианты товара: оттенки и объёмы.** Оттенки — кружки цвета в карточке (нажатие меняет фото, «+N» ведёт
на страницу), цена общая, фото оттенка обязательно. Объёмы — своя цена у каждого, в карточке «от …». На странице
товара выбор варианта, ссылка `?v=` запоминает его. В корзине и заказе — конкретный вариант. В админке блок
«Варианты» в форме товара, в Excel — лист «Варианты».

**Страницы брендов** (`/ru/brands`, `/ru/brands/<бренд>`): баннер бренда (фото из админки или витрина его хитов
на фоне цвета бренда), подзаголовок, страна, рейтинг, каталог с фильтрами только по бренду, «О бренде», вопросы
и ответы (с разметкой для поиска), другие бренды. Оформление и тексты — в админке, раздел «Бренды». Страница
появляется сама, как только у бренда есть товары.

**Личный кабинет покупателя.**
- Вход из любого места: страница профиля или шторка поверх текущей страницы (номер → код в Telegram).
  Гостю, добавившему 3 товара в избранное, вход предлагается один раз за визит.
- Сессия продлевается при каждом визите: активный покупатель не выходит из аккаунта. «Выйти на всех устройствах».
- Корзина и избранное хранятся в аккаунте: при первом входе на устройстве — слияние, дальше аккаунт главный.
- Профиль: данные, язык, рассылка; адреса с названиями и основным адресом; страница заказа с этапами и
  «Купить снова»; удаление аккаунта (недоступно, пока заказ в пути).
- Оформление для вошедших — один экран: сохранённый адрес и способ оплаты прошлого заказа уже выбраны.

**Партнёрка креаторов.**
- Креатор входит в кабинет `/creator` по своему номеру (номер указывает админ в карточке креатора).
- Сам создаёт короткие ссылки `/c/<код>/<id>` на товар, категорию, свой набор или главную; QR-код и текст для сторис.
- Переходы считаются на сервере, боты-превью (Telegram, Instagram, WhatsApp) отсекаются.
- Кому засчитан заказ: введённый код → переход по ссылке (30 дней, кука) → переход, закреплённый за номером
  (покупка с другого устройства) → окно 60 дней для нового клиента. Окно открывается только если это первый
  заказ клиента. Покупка на номер креатора — без комиссии.
- Комиссия: ждёт доставки → 7 дней на возврат → к выплате → выплачено. Отмена после выплаты — вычет из следующей.
- Выплаты 1, 11 и 21 числа: ведомость в админке и в Excel, кнопка «Отметить выплату».
- Админ видит воронку, долю новых клиентов, затраты на креатора, метки риска; может вручную перепривязать заказ
  с указанием причины. Креатор не видит имён и телефонов покупателей.

## API

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/auth/otp/request` | отправить код на номер |
| POST | `/api/auth/otp/verify` | проверить код, войти |
| POST | `/api/auth/profile` | сохранить анкету |
| GET | `/api/auth/me` | текущий клиент, последний адрес, заполненность |
| POST | `/api/auth/logout` | выйти |
| POST | `/api/orders` | создать заказ |
| GET | `/api/orders` | мои заказы |
| GET | `/api/promo?code=` | проверить промокод |
| GET | `/api/files/...` | загруженные фото товаров |
| GET | `/api/admin/export/{orders,products,customers}` | выгрузка в Excel (только админ) |
| POST | `/api/admin/import/products[?dry=1]` | загрузка товаров из Excel (только админ) |
| GET | `/api/admin/export/payouts` | ведомость выплат креаторам |
| GET | `/c/<код>[/<id>]` | короткая ссылка креатора |

## Изображения

- `public/images/icons/` — 3D-иконки категорий (WebP с прозрачностью, 480×480).
- `public/images/hero/` — фоны главного баннера для десктопа и телефона.
- Новые иконки на белом фоне: `python3 scripts/cutout-icons.py spf.jpg toner.jpg` — скрипт вырежет фон,
  обрежет по объекту и сохранит `public/images/icons/<имя>.webp` (нужны `pip install pillow numpy scipy`).
- Фото товаров не генерируются: только настоящие снимки или фото производителя.

## Как подключить Telegram

1. **Уведомления о заказах.** Создайте бота у @BotFather, добавьте его в группу менеджеров,
   узнайте id группы (например, через @getidsbot). Впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_ID`.
2. **Коды подтверждения.** Зарегистрируйтесь на gateway.telegram.org, пополните баланс,
   скопируйте токен API в `TELEGRAM_GATEWAY_TOKEN`. Код стоит $0.01, недоставленные не оплачиваются.
