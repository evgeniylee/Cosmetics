# NABI — интернет-магазин корейской косметики

Next.js 15 (App Router) + Tailwind CSS 4 + TypeScript + PostgreSQL. Языки RU/UZ, mobile-first.
Полное ТЗ: `docs/prompt.md`. Промты для изображений: `docs/image-prompts.md`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000 → /ru
```

Устанавливать PostgreSQL локально не нужно: без `DATABASE_URL` используется встроенная база PGlite,
данные лежат в `./.data/pglite` (в git не попадают). Чтобы начать с чистой базы, удалите папку `.data`.

В `npm run dev` вход работает в демо-режиме: код подтверждения `111111`.

Продакшен-сборка: `npm run build && npm start`. Настройки — в `.env.local` по образцу `.env.example`.

## Что готово

**Этап 1 — витрина.** Дизайн-система, поиск с транслитом, главная с каруселью, каталог с фильтрами,
страница товара, корзина с промокодами креаторов, анимации, меню каталога, аналитика `track()`.

**Этап 2 — бэкенд.**
- База данных: клиенты, адреса, анкета (вопросы хранятся в таблице `profile_questions`), сессии,
  коды подтверждения, заказы, события. Миграции в `src/server/migrations.ts` применяются автоматически.
- Вход по телефону через Telegram Gateway: `checkSendAbility` → `sendVerificationMessage` →
  `checkVerificationStatus`. Лимиты: 3 кода на номер за 15 минут, 5 номеров с одного IP в час,
  5 попыток ввода на код. Сессия в httpOnly-куке на 90 дней.
- Анкета нового клиента: имя, фамилия, дата рождения (14+), согласие, подписка на акции. Привязка
  к UTM и коду креатора из первого визита.
- Нет Telegram у номера — заказ принимается без кода со статусом «Требует звонка».
- Заказы: цены, скидки и доставка считаются только на сервере. Уведомление о каждом заказе
  приходит в Telegram-чат менеджера.
- Профиль: заказы со статусами, «Купить снова», заполненность профиля, выход.

## API

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/auth/otp/request` | отправить код на номер |
| POST | `/api/auth/otp/verify` | проверить код, войти |
| POST | `/api/auth/profile` | сохранить анкету |
| GET | `/api/auth/me` | текущий клиент, последний адрес, заполненность |
| POST | `/api/auth/logout` | выйти |
| POST | `/api/orders` | создать заказ |
| GET | `/api/orders` | мои заказы |

## Как подключить Telegram

1. **Уведомления о заказах.** Создайте бота у @BotFather, добавьте его в группу менеджеров,
   узнайте id группы (например, через @getidsbot). Впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_ID`.
2. **Коды подтверждения.** Зарегистрируйтесь на gateway.telegram.org, пополните баланс,
   скопируйте токен API в `TELEGRAM_GATEWAY_TOKEN`. Код стоит $0.01, недоставленные не оплачиваются.
